# 学习文档导航

欢迎！这是一套面向**前端开发**的 AI Agent 开发学习文档，帮助你从零开始理解本项目。

## 📚 文档结构

文档按**由浅入深**的顺序组织，建议按顺序阅读：

### 基础篇（必读）

1. **[01-快速上手-跑起来并会用.md](01-快速上手-跑起来并会用.md)**
   - 🎯 **目标**：成功运行服务并理解基本架构
   - ⏱️ **时间**：15-20 分钟
   - ✅ **完成后**：你能在本地运行服务，用 curl 测试 API，在 Streamlit UI 中对话

2. **[02-从一次请求看懂系统-HTTP到Agent图.md](02-从一次请求看懂系统-HTTP到Agent图.md)**
   - 🎯 **目标**：理解 HTTP 请求如何传递到 LangGraph Agent
   - ⏱️ **时间**：20-25 分钟
   - ✅ **完成后**：你能追踪一次请求的完整流程，理解 invoke/stream 的区别

3. **[03-AI与Agent基础概念速查-对照本项目.md](03-AI与Agent基础概念速查-对照本项目.md)**
   - 🎯 **目标**：掌握 AI/Agent 开发的核心术语
   - ⏱️ **时间**：25-30 分钟
   - ✅ **完成后**：你能理解 LLM、Tool、Graph、Memory 等概念，并知道在代码中的位置

4. **[04-疑难点与易错点清单-以本项目为例.md](04-疑难点与易错点清单-以本项目为例.md)**
   - 🎯 **目标**：避免常见错误，掌握调试技巧
   - ⏱️ **时间**：20-25 分钟
   - ✅ **完成后**：你能排查常见问题，理解工具调用、streaming、interrupt 等机制

### 进阶篇（可选）

5. **[10-入门RAG-从create_chroma_db到rag_assistant.md](10-入门RAG-从create_chroma_db到rag_assistant.md)**（待创建）
   - 🎯 **目标**：深入学习 RAG（检索增强生成）
   - 📝 **内容**：向量数据库、embedding、chunking、检索策略

6. **[11-MCP入门-以github-mcp-agent为例.md](11-MCP入门-以github-mcp-agent为例.md)**（待创建）
   - 🎯 **目标**：理解 MCP（Model Context Protocol）
   - 📝 **内容**：MCP 工具、GitHub MCP Agent、工具编排

## 🚀 快速开始

如果你是**第一次接触**这个项目：

1. **先读文档 01**：确保能运行起来
2. **再读文档 02**：理解系统架构
3. **然后读文档 03**：学习基础概念
4. **最后读文档 04**：掌握常见问题

**总时间**：约 1.5-2 小时
