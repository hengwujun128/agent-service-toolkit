## 📖 项目是什么？

这个项目是一个**完整的 AI Agent 服务工具包**，包含三个核心组件：

```
┌─────────────┐      HTTP/SSE      ┌──────────────┐      LangGraph      ┌─────────────┐
│  Streamlit  │ ◄──────────────── │   FastAPI    │ ◄───────────────── │   Agent     │
│     UI      │                    │   Service    │                    │   Graph     │
└─────────────┘                    └──────────────┘                    └─────────────┘
   (前端界面)                          (HTTP 服务层)                        (AI 工作流)
```

- **LangGraph Agent**：定义 AI 的工作流程（思考 → 调用工具 → 返回结果）
- **FastAPI Service**：把 Agent 暴露为 HTTP API（`/invoke`、`/stream`、`/info`）
- **Streamlit UI**：提供聊天界面，调用 FastAPI 服务

**类比前端开发**：
- LangGraph ≈ 状态机/工作流引擎（类似 Redux 的 reducer）
- FastAPI ≈ Express/Koa（HTTP 框架）
- Streamlit ≈ React/Vue（但更简单，用 Python 写 UI）

## 🚀 最小可运行步骤

### 步骤 1：配置环境变量

在项目根目录创建 `.env` 文件，至少配置一个 LLM API Key：

```bash
# 至少需要配置一个（推荐 OpenAI，最容易上手）
OPENAI_API_KEY=sk-your-openai-api-key-here

# 可选：如果你想用其他模型
# ANTHROPIC_API_KEY=sk-ant-your-key
# GOOGLE_API_KEY=your-google-key
```

**⚠️ 常见坑 1：Key 不生效**
- 确保 `.env` 文件在**项目根目录**（与 `README.md` 同级）
- 确保没有多余的空格：`OPENAI_API_KEY=sk-xxx`（不要写成 `OPENAI_API_KEY = sk-xxx`）
- 如果使用 Docker，确保 `.env` 在 `docker-compose.yaml` 的 `env_file` 中

### 步骤 2：安装依赖

项目使用 `uv` 作为包管理器（类似 npm/yarn）：

```bash
# 安装 uv（如果还没有）
curl -LsSf https://astral.sh/uv/install.sh | sh

# 安装项目依赖（会自动创建 .venv）
uv sync --frozen

# 激活虚拟环境
source .venv/bin/activate
```

**⚠️ 常见坑 2：Python 版本**
- 需要 Python 3.11、3.12 或 3.13（见 `pyproject.toml`）
- 如果 `uv sync` 报错，检查 Python 版本：`python --version`

### 步骤 3：启动服务

**终端 1：启动 FastAPI 服务**

```bash
source .venv/bin/activate
python src/run_service.py
```

你应该看到类似输出：
```
INFO:     Started server process [xxxxx]
INFO:     Waiting for application startup.
INFO:     Application startup complete.
INFO:     Uvicorn running on http://0.0.0.0:8080
```

**终端 2：启动 Streamlit UI**

```bash
source .venv/bin/activate
streamlit run src/streamlit_app.py
```

你应该看到：
```
You can now view your Streamlit app in your browser.
Local URL: http://localhost:8501
```

### 步骤 4：验证服务

**方法 1：浏览器访问 Streamlit**
- 打开 `http://localhost:8501`
- 你应该看到聊天界面，可以输入消息与 Agent 对话

**方法 2：curl 测试 API**

```bash
# 查看可用的 agents 和 models
curl http://0.0.0.0:8080/info

# 应该返回 JSON，包含：
# - agents: 可用的 agent 列表
# - models: 可用的模型列表
# - default_agent: 默认 agent（通常是 "research-assistant"）
# - default_model: 默认模型
```

**方法 3：测试 invoke 端点**

```bash
curl -X POST http://0.0.0.0:8080/invoke \
  -H "Content-Type: application/json" \
  -d '{"message": "Hello, what can you do?"}'
```

## 🔍 理解服务架构

### 服务启动流程

当你运行 `python src/run_service.py` 时，发生了什么？

1. **加载环境变量**（`load_dotenv()`）
2. **初始化 Settings**（`src/core/settings.py`）
   - 检查至少有一个 LLM API Key
   - 根据可用的 Key 决定默认模型
3. **启动 FastAPI 应用**（`src/service/service.py`）
   - 在 `lifespan()` 中初始化数据库（用于记忆）和加载所有 agents
   - 注册路由：`/info`、`/invoke`、`/stream`、`/history`、`/feedback`
4. **Uvicorn 启动 HTTP 服务器**（监听 `0.0.0.0:8080`）

**对应代码入口**：
- 启动脚本：[`src/run_service.py`](src/run_service.py)
- FastAPI 应用：[`src/service/service.py`](src/service/service.py)
- 设置配置：[`src/core/settings.py`](src/core/settings.py)

### Agent 注册表

所有可用的 agents 定义在 [`src/agents/agents.py`](src/agents/agents.py)：

```python
agents: dict[str, Agent] = {
    "research-assistant": Agent(...),  # 默认 agent
    "rag-assistant": Agent(...),
    "chatbot": Agent(...),
    # ... 更多 agents
}
```

**默认 agent**：`research-assistant`（带网络搜索和计算器工具）

### Streamlit UI 如何连接服务

Streamlit 使用 `AgentClient`（`src/client/client.py`）与 FastAPI 通信：

1. **初始化时**：调用 `/info` 获取可用 agents 和 models
2. **发送消息时**：调用 `/{agent_id}/stream` 或 `/{agent_id}/invoke`
3. **流式响应**：使用 Server-Sent Events (SSE) 接收 token 流

**对应代码入口**：
- Streamlit 主文件：[`src/streamlit_app.py`](src/streamlit_app.py)
- 客户端实现：[`src/client/client.py`](src/client/client.py)

## ⚠️ 常见问题排查

### 问题 1：服务启动失败，提示 "At least one LLM API key must be provided"

**原因**：`.env` 文件中没有配置任何 LLM API Key

**解决**：
1. 检查 `.env` 文件是否存在且包含至少一个 Key
2. 确保 Key 格式正确（没有多余空格）
3. 如果使用 Docker，检查 `compose.yaml` 中的 `env_file` 配置

### 问题 2：端口 8080 或 8501 已被占用

**解决**：
```bash
# 查看占用端口的进程
lsof -i :8080
lsof -i :8501

# 杀死进程（替换 PID）
kill -9 <PID>

# 或者修改端口（在 .env 中）
PORT=8081  # 修改 FastAPI 端口
# 在 streamlit_app.py 中修改默认端口，或使用环境变量
```

### 问题 3：Streamlit 无法连接到服务（"Error connecting to agent service"）

**原因**：
- FastAPI 服务未启动
- 端口不匹配
- 防火墙/网络问题

**解决**：
1. 确认 FastAPI 服务正在运行（检查终端 1）
2. 检查 `AGENT_URL` 环境变量（Streamlit 会读取）
3. 默认情况下，Streamlit 会连接 `http://0.0.0.0:8080`

### 问题 4：模型调用失败（401/403/429 错误）

**原因**：
- API Key 无效或过期
- API 配额用完
- 网络问题

**解决**：
1. 检查 API Key 是否正确（可以在 OpenAI 官网测试）
2. 检查账户余额/配额
3. 尝试其他模型（修改 `.env` 中的 Key）

### 问题 5：Docker 与本地环境变量不同步

**原因**：Docker 容器内的 `.env` 与本地不同

**解决**：
- 确保 `compose.yaml` 中正确配置了 `env_file`
- 或者直接在 `compose.yaml` 的 `environment` 中设置变量
